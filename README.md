# HR AI Builder

面向 HR 的 AI 系统课程与能力体系。**课程、能力词典、真实岗位库、脱敏数据集与能力测评，全部免费开放。**

> 读懂 AI 的底层逻辑，做 AI Native 组织的先驱者。

## 这是什么

AI 正在重写每一个组织的运行方式——怎么分工、怎么配人、能力怎么迁移。这些本来就是 HR 的命题，
所以 HR 本该是最先看懂这件事的人。

本站从大模型的底层逻辑讲起，一路到能亲手做出第一个可用的东西，全部内容从 HR 场景倒着写。

## 核心设计

**能力词典按 KSA 分类**，因为这三类补起来的代价完全不同：

| | 补起来要多久 | 会不会过时 | 怎么考 | 差了怎么办 |
|---|---|---|---|---|
| **K 知识** | 天～周 | 快 | 问概念 | 立刻补 |
| **S 技能** | 周～月 | 中 | 看作品 | 做作品 |
| **A 能力** | 年 | 不过时 | 行为面试 | 补不了，只能被重新证明 |

测评也按这三类**分开给分**，不合并成一个总分——合并会掩盖「你差的到底是能补的还是补不了的」。

## 本地运行


# HR AI Builder

> 读懂 AI 的底层逻辑，做 AI Native 组织的先驱者。

面向 HR 的 AI 系统课程与能力体系。**课程、能力词典、真实岗位库、脱敏数据集与能力测评，全部永久免费开放。**

本项目是 **[洛小山](https://luoxiaoshan.cn/)《AI 产品从入门到精通》（[learn-ai](https://github.com/itshen/learn-ai) · [xueai.app](https://xueai.app)）的领域衍生作品**，依 **AGPL-3.0** 开源并保留原作者署名。

原课程面向 AI 产品经理与开发者，把 AI 的底层原理讲得极其通俗——这是它最了不起的地方，我们没有理由重造。
本项目做的是**另一件事**：把它切进 HR 这个更细分的领域。

具体做了三件事：

| | 数量 | 说明 |
|---|---|---|
| **沿用** `copy` | 43 节 | 内容通用，HR 同样适用，原样保留 |
| **改写** `adapt` | 23 节 | 沿用骨架，重写成 HR 场景 |
| **原创** `new` | 16 节 | learn-ai 中不存在——只有 HR 才写得出的部分 |

原课程 231 节，我们保留约 30%（删去 Grok Build Rust 源码解剖、Harness 自我改进、AI 生图、成本工程细节等对 HR 无用的部分），
再补进 16 节 HR 独有内容，共 **9 篇章 · 31 节 · 92 个知识点**。

**为什么要删这么多**：原课程是「向下」的——理解 AI 怎么工作的。
HR 需要的是「向外」——理解它在我的场景里能干什么、会怎么坏。方向不同，不是深浅不同。

## 内容设计

### 一、每节都是三段式，不单独设「通用基础章」

通用原理一个字不少讲，但它被夹在两个 HR 场景中间：

1. **场景开场** —— 你让 AI 从 200 份简历里筛人，它返回了「阿里 AI 中台项目负责人」。你翻原文——简历里根本没有「阿里」二字。
2. **原理解释** —— 它不是在检索，是在**补全**。它见过成千上万份简历，知道「像简历的文本」长什么样，于是把最像的那个词填了进去。
3. **回到场景，给一条能执行的规则** —— 所以 **AI 只能做召回，判定必须回原文**。这是一道闸，写进流程，不是写进备忘录。

（例外：第零篇章是纯通用总览，零基础可看，全章免费。）

### 二、能力词典按 KSA 分类

这三类补起来的代价完全不同，所以测评也**分开给分**，不合并成总分——合并会掩盖「你差的到底是能补的还是补不了的」。

| | 补起来要多久 | 会不会过时 | 怎么考 | 差了怎么办 |
|---|---|---|---|---|
| **K 知识** | 天～周 | 快 | 问概念 | 立刻补 |
| **S 技能** | 周～月 | 中 | 看作品 | 做作品 |
| **A 能力** | 年 | 不过时 | 行为面试 | 补不了，只能被重新证明 |

### 三、课程有三种形态，不是一种

| | 能不能"教" | 形态 | 学完手上多了什么 |
|---|---|---|---|
| K | 能 | 讲解 + HR 场景实例 | 一个判断依据 |
| S | 教不会，只能**带做** | 步骤 + 数据集 + 模板 | **一个能跑的东西** |
| A | 教不了，只能**校准** | 真实两难 → 你先判断 → 再看拆解 | **一次被修正的判断** |

## 结构

```
frontend/
  index.html         首页
  course-data.js     课程单一真相源（含每节的 action 与 KSA 标注）
  slides/            课件（66 节沿用/改写自 learn-ai + 16 节原创待写）
  demo.html          岗位拆解 / 作品选题库 / 能力测评原型
backend/
  main.py            内容与测评 API
  wechat.py          微信登录（开放平台 OAuth + 小程序扫码双轨）
  auth.py            JWT 会话
render.yaml          Render Blueprint（静态站 + API）
```

## 本地运行

```bash
cd frontend && python3 -m http.server 8000        # 前端
cd backend && pip install -r requirements.txt && uvicorn main:app --reload --port 8001
```

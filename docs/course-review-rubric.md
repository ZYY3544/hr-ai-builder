# 课程审查标准（Course Review Rubric）v1

> 用途：逐章审查课程质量的常设量具。每次大改课程后重跑。
> 产出格式：每条 finding 必须带【文件:位置 + 引原文证据 + 严重度】，不许只给形容词。
> 严重度：🔴 用户会被误导或卡住 / 🟡 体验或结构缺陷 / ⚪ 打磨项。

## A. 章级结构（整章看）

| # | 判据 | 怎么查 |
|---|------|--------|
| A1 | **知识点不重不漏** | 把章内每节的核心知识点列成清单。重：同一概念在两节都当主内容讲（≠案例重现）。漏：章标题/desc 承诺的范围里，一个 HR 实际会撞到的关键问题没有任何一节接住 |
| A2 | **递进链完整** | 按节序检查依赖：第 n 节是否用了第 n+k 节才定义的术语（前向引用）。每节开头是否接得住上一节的结尾 |
| A3 | **难度曲线平滑** | 从直觉→原理→操作是否渐进，有无某一节突然跳崖（前一节还在打比方，下一节直接上参数） |
| A4 | **章的完成感** | 章末是否有收束（回顾/串联/通向下一章的钩子），还是最后一节讲完戛然而止 |

## B. 节级体验（每节单独看）

| # | 判据 | 怎么查 |
|---|------|--------|
| B1 | **三段式兑现** | HR 场景→原理→能执行的规则，三段是否都真实存在。重点打假第三段：规则是否真的能执行（有主语有动作有判断条件），还是正确的废话（"要注意平衡"类） |
| B2 | **标题承诺兑现** | 标题/目录 desc 提出的问题，正文是否正面回答。标题党 = 🔴 |
| B3 | **认知负荷** | 一节引入的新术语 >3 个挂旗；每个新术语是否当场给了直觉解释 |
| B4 | **受众一致性** | 说话对象始终是 HR；例子是 HR 场景；不假设读者懂技术。残留其他受众痕迹 = 🔴（已发生过：PM 残留） |
| B5 | **交互当量** | 页内交互（点击展示/自测题）是否服务理解，还是装饰性点击。坏交互：点完不改变认知的 |

## C. 跨节一致性

| # | 判据 | 怎么查 |
|---|------|--------|
| C1 | **口径一致** | 同一术语跨节定义一致（幻觉/召回/判定/温度/RAG…）。跨节矛盾 = 🔴 |
| C2 | **案例具体性** | 每节至少有一个具体 HR 案例做地基（人物/数据/对话，可追问细节），不许纯框架推演；同一案例跨节复用时须有增量（见 D）。※ 2026-08-11 起取消"主线案例"包装，案例多元轮转：简历初筛/薪酬口径/制度问答/组织盘点 |
| C3 | **K/S/A 标注属实** | 标 S 的节要有"做"的成分（可跟着操作的东西），标 A 的节要落在判断力（何时用/何时不信），标错 = 🟡 |
| C4 | **规则相互兼容** | 各节给出的"能执行的规则"放在一起是否打架（一节说"永远抽查"，另一节说"信置信分"） |

## D. 重复判定（MECE 的课程化改造）

| 类型 | 定义 | 判法 |
|------|------|------|
| 坏重复 | 同一知识点在两节都当主内容，讲法或口径不一致 | 🔴 修：合并或改从属引用 |
| 灰重复 | 同一知识点重讲但口径一致、无增量 | 🟡 修：后一处改成一句话回指 + 链接 |
| 好重复 | 同一案例/规则在新知识点下重现，带新视角或新操作 | ✅ 保留（这是主线案例的设计意图） |

## 阳性对照（每次跑 rubric 前先验刀）

rubric 必须能抓出以下已知问题，抓不出说明量具是钝的：
1. `hr-org-1.html` —— 纯框架无真实案例（违反 B1 第三段/主线案例）
2. 8 节挂「✎ 待补真实素材」banner 的节（知识萃取 3 / 口径战争 3 / 组织重设计 2）
3. 历史问题：改写章与沿用章之间表述风格断裂（A2/C1 类）

## 审查产出模板

```
## 第 N 篇章《标题》
### 阳性对照：抓到 x/y
### 🔴 findings（文件:位置 + 证据引文 + 修法）
### 🟡 findings
### ⚪ findings
### 章级判定：可发布 / 修完🔴可发布 / 需要重构
```

# meansights / 铭曦 — 标识使用说明

配色 **Graphite**：石墨 `#1E2226` × 青绿 `#0FB2B8`。
字标已转成矢量轮廓，任何机器打开都不会因缺字体而变形。

---

## 该用哪个文件

| 场景 | 用这个 |
|---|---|
| 官网 header、产品左上角、PPT 首页 | `02 渐变字标版/lockup-横排-渐变.svg` |
| 文档页脚、名片、签名档、小尺寸任何地方 | `01 主版/lockup-横排.svg` |
| 方形或窄版面（易拉宝、封面、卡片） | `01 主版/lockup-竖排.svg` |

**只要标记不带字标**（够小、或旁边已经有公司名），用各目录里的 `mark-标记*.svg`。

## 两条硬规矩

**1. 渐变版只在浅底、24px 以上用。**
13px 尺寸下渐变读不出来，只会剩一个说不清的偏色墨。页脚落款、favicon、单墨、深底反白，一律回主版纯色。用错场景比不用渐变更掉价。

**2. 青绿全局只出现一处。**
标记里只有第四根光柱是青绿，三根 M 柱始终是石墨色。渐变字标里青绿只在词尾。一旦第二处也用了青绿，那一点亮就不值钱了。

---

## 几何（不要改）

- 柱宽 8u、步距 13u、柱高 **28 / 16 / 28**、光柱 4→56u
- 柱 1 与柱 3 **严格等高**，三个顶点连起来才是 M 的轮廓；差一点就散成随机柱状图
- 第四根不属于 M，它是越过 M 的那道曦光——宽度与柱子一致，只在高度上出格
- 字距 **+16‰**，光柱右缘到字标起笔 = 字号的 **0.66 倍**
- 组合时**柱底坐在字母基线上**，`g` 的下伸部落在基线以下，这是对的

标记 SVG 顶部有一段渐隐区（几乎透明）。做垂直居中时以整个 viewBox 为准，不要按肉眼可见的部分对齐。

---

## 别这么用

- 不要拉伸变形——等比缩放
- 不要给标记加描边、阴影、外发光
- 不要改柱子高度比例或根数
- 不要把青绿换成别的颜色，也不要给三根 M 柱上色
- 不要在深底上用主版（青绿会发闷），换反白版
- 不要在照片或花底上直接放——加一块纯色底再放

## 字体说明

字标用 **Geist**（SIL OFL 1.1，可自由商用、可用于商标），字形已转为路径，成品文件不含字体依赖。

**没有用 SF Pro**：Apple 的字体许可禁止把字形用于 logo 和商标。而且 Geist 本来就是你既定设计系统里的字体。

## 要改的时候

`_源文件/` 里有生成脚本。改颜色、字重、字距、几何常量都在 `build_logo.py` 顶部：

```bash
cd "_源文件"
python3 -m venv venv && ./venv/bin/pip install fonttools brotli
./venv/bin/python build_logo.py    # 重出全部 SVG
./venv/bin/python build_png.py     # 重出全部 PNG
```

脚本重跑时会清空 `01`–`06` 这些编号目录再重建（`_源文件/` 和本说明不受影响），
所以别把手改过的文件放进编号目录里。

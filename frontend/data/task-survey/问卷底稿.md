# 新人融入调研 · 静态问卷底稿（星云科技，虚构公司）

这是行政下发的现行版本——典型的静态问卷。你的任务不是填它，是把它改造成一个**会追问的对话式调研 agent 的设计方案**。

## 现行问卷（入职满一个月的新人填写）

**锚点题**（1-5 分打分）
- A1 入职流程顺畅程度
- A2 我清楚自己的工作目标和考核标准
- A3 我需要的权限/设备/系统账号及时到位
- A4 直属主管在我入职首月给了足够的支持
- A5 我知道遇到问题该找谁
- A6 团队让我感到被欢迎
- A7 培训内容对我上手工作有帮助
- A8 我愿意向朋友推荐来这里工作（0-10 分）

**开放题**
- E1 入职以来最让你受挫的一件事是什么？
- E2 如果能改进一件事，你会选什么？

## 已知的问题（HR 的原话）

- 分数收上来一堆 3 分 4 分，**不知道 3 分背后发生了什么**
- 开放题一半人写"暂无"，写了的也常是一句空泛的感受（"节奏有点快"）
- 想逐个访谈没有人力：每月入职 40+ 人

## 你的产出（设计文档，不写代码）

1. **追问触发规则**：哪些题、什么分数触发追问？为什么是这些？
2. **追问阶梯设计**：追问要把"感受"变成什么？分几层、每层的目标是什么、最多追几层？
3. **预算与止损**：整卷最多追问几次（要守住"10 分钟填完"的承诺）？用户敷衍/跑题时怎么办？
4. **分工书**：这套流程里，哪些决定由固定规则做、哪些交给大模型做？为什么这么分？
5. **两段真实的追问 prompt**：挑两个场景（如 A2 打了 2 分 / E1 写了"感觉没人带"），写出你会发给模型的完整 prompt。

评审看的是**结构判断**：规则和模型的分工是否清醒、追问是否在把感受翻译成事实、预算是否守得住承诺。

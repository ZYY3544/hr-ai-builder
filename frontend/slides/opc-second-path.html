课后甜点 · 一人公司 OPC

把你的 agent 变成一人公司

这门课一直在讲怎么走向那些 AI-HR 岗位。但去岗位不是唯一的出路——你手上能跑的 agent，本身就是一个可以收钱的产品。

这条路为什么成立

三个事实，一个都不玄：

1绝大多数中小企业没有专职的 HR 专家。月报没人会做、调研收上来没人会读、面试全凭老板感觉——这些活在大厂有整个部门，在几十人的公司里压在一个行政身上。他们不缺意愿，缺的是「有人能把这事做了」。
2你手上的东西就是产品。实战任务里做的人力月报、会追问的调研 agent、面试官 prep——把公司名换掉，它们就是可以按次交付的服务。你不是「想创业但没有产品」，你是做完任务包那一刻就有了。
3执行免费了，判断力涨价。第九篇章讲过这句话。放在生意层它意味着：客户买的不是「会用 AI」，是你判断口径对不对、数能不能对上的那双眼睛——这正是这门课从头到尾在练的东西。
服务谁，第一单从哪来

先把一个幻想掐掉：第一单不来自平台、不来自投广告、不来自「做个官网等人找上门」。第一单永远来自已经认识你的人。

找谁他们的痛你交付什么
前同事、老东家的上下游知道你靠谱，但不知道你现在会这个把你做的东西发一遍给他们看——不是发简历，是发作品
HR 社群里喊「谁会做这个」的人活已经砸手里了，明天就要接下来，按次收费，做完让结果说话
身边正在被数据折磨的小公司每月手搓报表，错了还得背锅「我帮你把这个月报做成每月自动跑」——一句话就能听懂的东西

定价从按次交付、一口价开始：一单多少钱、交付什么、几轮修改，说清楚。先把「交付 → 验收 → 收款」完整走通一遍，订阅制、按月托管都是有了复购之后才谈的事。

别这样开场「我在学 AI，有没有什么可以让我试试的？」——这是在要人情，对方只能施舍你一个练手机会，练完也不会付钱。
这样开场「你们每月的人力月报是谁在做？我做了一个能自动跑的，你看下这个样例——第一单半价，数对不上不收钱。」——这是在卖交付，对方拒绝你也知道你是干什么的。
收钱之前，要办的只有三件事
①有个能收款的主体。注册一个个体户（大多数城市线上就能办完），能开收据、走对公，客户财务才有办法给你打钱。没有主体，单子谈成了也收不了款。
②一页纸服务协议。四样东西写死：交付物是什么、验收标准是什么（对得上哪张数）、改几轮、数据怎么处理。不用律师，但必须有——它保护的不是你被赖账，是双方对「做完」的定义一致。
③数据红线。客户的真实员工数据，不进你的个人 AI 账号——第六篇章《你的数据到底走了哪条线》那条线，出来接活同样成立，而且更严：在公司内犯错是事故，替客户犯错是官司。方案里就写明数据在哪跑、你留不留底。
商标、软著、专利、域名备案——这些确权动作是有了复购之后的事。第一单之前在这上面花的每一分钱和每一天，都是在用「筹备」逃避「去卖」。真到需要那天，这些都有成熟的代办，一周办完。
这一节不是创业课

一人公司这个话题能讲一整门课：定位、获客、复购、提价、外包。这一节只负责一件事——让你知道这条路存在，并且第一步比想象中小得多：一个作品、一个熟人、一张一页纸协议。

想法层面的事——「谁会付钱」「为什么是现在」「最小能交付的版本长什么样」——可以拿去跟右下角的 Sparky 掰扯，它会追问你。但要诚实：聊天磨的是想法，公司是做出来的。产品得回 Claude Code 里做，客户得你自己开口去找，这两步没有任何对话能替你走。

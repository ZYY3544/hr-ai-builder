第六篇章 · 先把工具装上：终端与 Claude Code

为什么是终端里的 Claude Code

市面上教 HR 搭 agent 的，用的几乎都是拖拽平台。这一节说清楚我们为什么不走那条路——不是因为它不好用，是因为它的天花板是别人给你定的。

两条路的区别
拖拽平台（扣子 / Dify / 各家智能体工场）终端里的 Claude Code
上手十分钟出一个能聊天的东西要装、要敲命令，第一次约半小时
能力边界平台给你划好的那些节点你的电脑能做的，它基本都能做
数据整份文件传上去，存在平台的服务器上文件存在你自己硬盘上，但内容还是要发给模型——差别是你能控制发给谁、发哪一部分（本章有一节专讲）
产出一个绑在平台上的配置一堆你自己的文件——可以拷走、可以给同事、可以放进作品集
学到什么这个平台怎么用agent 是怎么回事

看最后一行。平台学会了，换个平台你还得重学；这一套学会了，你换什么工具都成立——因为你学的是工具调用、上下文、权限这些东西本身。

对 HR 来说，还有两条硬理由
✓ 数据的控制权在你手上这里要说清楚，因为很多教程在这一点上是骗人的：不是"数据不出本地"。Claude Code 跑在你电脑上，但它读一个文件之后，会把内容发给模型才能得到回答——推理不在你的电脑上做。

真正的差别是控制权：拖拽平台是整份文件传上去、存在平台里、你说了不算；而在你自己电脑上，发不发、发哪一段、发给哪个服务商，是你决定的——你可以先在本地把数据脱敏、只把统计结果发出去，也可以把端点换成公司自己的。

这条链路值得单独讲一节——本章的《你的数据到底走了哪条线》就是它。在读完那一节之前，请只用假数据。
✓ 它能碰到你的真实工作你的活是散在几十个 Excel、几个文件夹、几份 Word 制度里的。拖拽平台碰不到这些——它只能处理你手动贴进去的东西。而终端里的 agent 可以直接读你的文件夹。
门槛说在前面，但它比传说中低
真实的门槛只有一件事要装一次东西，在一个黑框框里敲几行字，第一次多半会报错——就这些。

不需要 Anthropic 账号 · 不需要海外信用卡 · 不需要科学上网。Claude Code 是工具，背后的模型可以换成国产的——对这门课要做的活，国产模型完全够用（最难的那些活上还是有差距，但不在这门课的范围里）。下一节带你走完，跟着视频约 20 分钟。

如果你在网上看到"用 Claude Code 得先解决网络"，那说的是接官方 API 的走法——那条路我们不走。

而翻过这道坎的价值是真的：搭一个 agent 如果只需要拖几下，那它就不构成任何人的能力。你能自己造出一个跑起来的东西，这件事本身就是分水岭。

另外，Claude Code 也有桌面版和网页版。我们这门课坚持用终端版，因为完整的文件访问、自定义工具、子 agent、钩子这些能力只有终端版才全。学会终端版，桌面版你自然会用；反过来不成立。

今天就试先不装任何东西。只做一件事：在你电脑上找到「终端」这个程序，打开它，看一眼。Mac 上叫「终端 / Terminal」，Windows 上叫「PowerShell」或「终端」。就看一眼，关掉。下一节我们就在这里面干活。

第四篇章 · Code Interpreter 与沙箱：代码在哪跑，数据去哪了

三条路：代码在哪跑

这可能是最卡人的一关，但几乎没人教。三条路，按数据敏感度和使用频率选，没有一条需要你「会编程」。

三条路
路怎么跑适合代价
① 托管沙箱就是前面几节你一直在用的：AI 在对话里写代码、当场运行。零安装练手、假数据、脱敏数据、公开数据数据要上传——红线内的数据不能走
② 本地 Python让 AI 写好代码，你复制到自己电脑运行。装环境是一次性的，而且可以让 AI 全程带你装，装报错就把报错贴回去问敏感数据、大表、每月固化要跑的活首次装环境约半小时
③ Excel 宏（VBA）公司电脑装不了任何软件？Excel 自带 VBA、WPS 有宏，零安装。让 AI 写 VBA，你贴进宏编辑器运行，数据全程不离开那张表受管控的办公电脑 + 敏感数据能力上限比 Python 低，但日常表格活绰绰有余
怎么选：两个问题

数据敏感吗？敏感 → 只能 ②③（或者把数据脱敏后走 ①）。
这活每月都跑吗？是 → 值得走 ②③ 固化成一个文件，以后双击就跑；只跑一次的临时活 → ① 最省事。

走 ③ 的话术
我在用公司电脑，不能安装任何软件，只有 Excel（版本 2016）。 请把刚才那个活写成 VBA 宏： - 数据在工作表「花名册」，结果写到新建的工作表「查重结果」 - 请给我打开 VBA 编辑器、粘贴、运行的具体步骤（我没用过宏） - 不要修改「花名册」表里的任何单元格
一个心理关

「装环境」「开宏编辑器」听起来像程序员的事？换个算法：装环境半小时是一次性的，你每月那三小时是永续的。而且你不是自学——你身边坐着一个有无限耐心、随叫随到的工程师，每一步卡住都能问它，报错原样贴回去就行。

这个时代「不会」的含义已经变了：不会 = 还没问。
三个活，走一遍选路
活数据敏感？每月都跑？选
练手 / 学新招 / 试话术用假数据否① 托管沙箱，最省事
每月经营月报（真花名册+薪酬）是是② 本地 Python，一次装环境，以后双击
公司电脑上临时查一批考勤异常是否③ Excel 宏，零安装，做完就删
走 ② 的人最常卡在哪

不是装 Python 本身，是装完之后不知道怎么把脚本跑起来。这一步直接问它，把你的系统告诉它：

我是 Windows 11（或 macOS），已经装好了 Python。 请一步步告诉我怎么运行你刚给我的脚本： - 脚本文件存到哪、叫什么名字 - 数据文件放哪 - 用什么命令运行，命令在哪个窗口里敲 - 我怎么知道它跑成功了 我完全没有编程经验，请把每一步的具体操作写清楚， 包括我该点哪里、看到什么就算对了。

最后那句是关键：「看到什么就算对了」——没有这句，它会默认你知道成功长什么样。

一个被低估的收益

走 ②③ 的活可以做成双击就跑的一个文件（Windows 上是 .bat，macOS 上是 .command，让它帮你写）。这一步看起来只是省了敲命令，实际意义大得多：

能双击运行，这个活才真的能交接。你休假的时候同事双击一下就出结果，不需要懂 Python，不需要看你的聊天记录——这是「只有我能跑」和「谁都能跑」的分界线。
今天就试给你清单上的每个活标一条路。标完你多半会发现：练手全走 ①，真正值钱的月度活几乎都得走 ② 或 ③——因为它们碰的都是真数据。

第六篇章 · 先把工具装上：终端与 Claude Code

你的数据到底走了哪条线

网上教 Claude Code 的内容里，有一句话被反复说，而它是错的：「跑在本地，所以数据不出本地」。这一节把链路拆开给你看，然后给你三条真能用在公司里的路。

先纠正一个流传很广的说法
✕ 「Claude Code 跑在你电脑上，所以花名册不会外传」这句话前半句对，后半句错。本地跑的只是那个壳。模型本身不在你电脑里——它在服务商的机房里，有几百上千张显卡。

你的电脑负责：读文件、执行命令、显示结果。「想」这个动作，从来不在你的电脑上发生。
上一节那句话，实际发生了什么

你问它「这个文件夹里有什么，每个文件多少行、列是什么」，它回答得很准。这中间的完整链路是：

1
你敲下问题，回车。
2
Claude Code 在你电脑上执行了一次"列出文件"，拿到文件名。
3
它把文件名连同你的问题，发给了模型服务商。
4
模型回答："我要读第一个文件。"
5
Claude Code 在你电脑上打开了那个文件。
6
它把文件里的内容发给了模型服务商。——花名册的每一个名字、每一个工号、每一行薪酬，都在这一步出去了。
7
模型读完，给出结论。Claude Code 显示在你屏幕上。

红色的那两步，就是你的数据出门的地方。它去了哪儿？去了你在装的时候填的那个地址——如果你按上一章配的是智谱，那就是智谱的服务器；如果你用的官方账号，那就是 Anthropic 的服务器。

为什么这件事必须现在说因为它决定了你能往那个文件夹里放什么。

第四篇章讲沙箱时那条红线原封不动地适用：员工花名册、薪酬明细、绩效、健康、背调——这些放进 data/ 目录，等于发给了外部服务商。「我是在本地跑的」不构成豁免理由，因为本地跑的不是模型。
自己验一次，别信我说的

这件事你可以在两分钟内自己看见，不用相信任何人的转述：

cd ~/Desktop/hr-agent claude

先去智谱控制台看一眼当前的额度消耗数字，记下来。然后让它读一个稍大的文件（几百行的假考勤表最好），读完之后刷新控制台再看一眼。

✓ 你会看到什么token 消耗涨了，而且涨的量跟文件大小成正比——文件越大涨得越多。

那些 token 就是你的文件内容。它按字数计费，因为它确实被送过去了。这是全课最值得你亲手做一遍的实验：不是听我说数据走了，是自己看见它走了。
那怎么办？三条路，按能不能过公司安全评审排
路数据发去哪能放什么 · 适合谁
① 个人账号
（你现在这条）		你个人注册的第三方 API，几十块钱的套餐。条款按个人用户算只能放假数据和脱敏后的数据。适合学习、做作品集、跑不含个人信息的公开数据。这门课全程按这条路教
② 公司统一采购的企业端点公司跟服务商签了合同的账号，有 DPA、有数据处理条款、能开发票看合同怎么签。这是把这套东西搬进公司的正路——你要做的是拿着方案去找 IT 和法务，而不是自己偷偷用个人 Key 跑真数据
③ 内网私有化部署公司自己机房里的开源模型，数据不出内网敏感数据可以碰。代价是能力比在线的旗舰模型弱一截、要有人维护。第三篇章讲私有化那节说的就是它
✓ 最实用的其实是组合拳第三篇章给过一个组合，在这里落地最合适：本地清洗 + 外部分析。

让 Claude Code 先写一个脚本，在你电脑上把花名册里的姓名、工号、身份证号去掉，换成编号；然后只把脱敏后的、聚合过的数据交给模型去分析。

脚本在本地跑，不需要发给模型；发出去的只有"技术部 P7 共 15 人，薪酬中位数 X"这种不含个人信息的东西。这样你既拿到了 AI 的分析能力，又没让任何一个员工的信息离开公司。
还有一件必须现在说清的事：提示词不是权限

本章《CLAUDE.md：让它记住你的口径》那节会教你写安全红线，比如「不许把 data/ 里的内容发到外部」。那些规则有用，但你必须知道它们的性质：它们是"请求"，不是"锁"。

✕ 为什么提示词挡不住第二篇章那一节的标题就是答案：「指令和数据走同一个通道」。你写在 CLAUDE.md 里的规则，和它读到的文件内容，最后是混在同一段文字里进模型的。

所以一份带注入的简历（第二篇章那个白色字体的例子）完全可以跟你的红线讲道理——它也是"指令"，凭什么你的优先级更高？只是因为你写了"最高优先级"这四个字吗？
✓ 真正的锁在配置文件里Claude Code 有一层不经过模型的权限配置：写在项目目录下的 .claude/settings.json 里。它由程序执行，模型说服不了它。

那节会给你完整的写法。这里你只要先记住一件事：凡是"绝对不能发生"的事，写进配置；凡是"希望它这么干"的事，写进 CLAUDE.md。两者不能互相替代。
这一节的三句话

本地跑的是壳，不是脑子

  1. 它读文件 = 文件内容发给模型服务商。「跑在本地」不等于「数据不出本地」，去控制台看一眼 token 消耗就能验证
  2. 个人账号只能放假数据。要碰真数据，走公司采购的企业端点或内网私有化——这不是绕路，这是唯一能过安全评审的路
  3. 提示词是请求，配置文件才是锁。绝对不能发生的事，别指望模型自觉
今天就试做那个 token 实验：记下控制台数字 → 让它读一个几百行的假表 → 再看数字。

然后做一件更有价值的事：把这条链路画成三行字，发给你们公司管信息安全的同事，问一句「如果我要用这个工具处理部门数据，走什么流程」。

这个动作的价值不在于他怎么答，在于你成了那个先问的人——而不是那个被发现之后才解释的人。

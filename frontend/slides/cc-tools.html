第六篇章 · 给它手和眼睛：工具、权限与第一个真活

工具：它能干什么，取决于你给了它什么

第四篇章讲过工具调用的机制。这一节讲清楚：一个 agent 的能力边界，就是它的工具清单。

记住这个判据就够了，别背工具名：agent 的能力边界 = 它的工具清单。它做不到某件事，通常不是"它不够聪明"，是它没有那只手。想清楚这一点，你排查问题的方向会完全不同。
加工具：MCP 是什么

自带工具之外，你可以给它接更多手——这套接法叫 MCP。你可以理解成"给 agent 装外设"：接上公司的 HR 系统、接上数据库、接上企业微信。

但这一节先别学 MCP接外部系统要过 IT、要权限、要接口——这些不是你现在该碰的。先用自带的四类工具做出一个真正能用的东西，那已经能覆盖你八成的活。MCP 等你有了真实需求再说，那时候你也知道该接什么了。
工具越多越好吗

不是。工具多了它会犹豫、会选错、会绕远路。这是下一章 harness 的核心议题之一。现在你只需要记住一个反直觉的事实：给 agent 减工具，常常比加工具更能提升它的表现。

今天就试问它一句：「你现在有哪些工具可以用？每个用一句话说明。」看它自己怎么描述自己的能力边界——这比读任何文档都直观。

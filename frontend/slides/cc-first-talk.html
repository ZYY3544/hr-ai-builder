第六篇章 · 先把工具装上：终端与 Claude Code

第一次对话：它看得见你的文件夹

装好之后第一件该做的事，不是让它干活，是搞清楚它和你用惯的网页版聊天，到底差在哪。

最根本的一个差别
网页版聊天：你把东西贴给它。
终端里的 Claude Code：它自己去看你的文件夹。

你在哪个文件夹里启动它，它就以那个文件夹为工作区。它可以列出里面有什么文件、打开来读、修改、新建、运行——就像一个坐在你电脑前的同事，而不是一个隔着窗口跟你对话的人。

动手感受一下

新建一个空文件夹（比如桌面上建一个叫 hr-agent 的），把两三份假的花名册/考勤表扔进去，然后在这个文件夹里启动它：

cd ~/Desktop/hr-agent claude

然后问它一句最简单的话：

这个文件夹里有什么？帮我看一眼， 每个文件是什么内容、有多少行、列是什么。

你会看到它自己去读了文件，然后告诉你结果——你没有点过任何"上传"按钮，它自己就把文件找出来看了。这个"它能主动够到你的文件"就是这一章后面所有内容的基础。

但先别误会一件事没点上传，不等于文件内容没有出去。它读完文件之后，得把内容发给模型才能回答你——推理不在你的电脑上做。

所以刚才让你扔进去的是假的花名册，这不是随口一说。下一节专门讲这条链路：你的数据到底走了哪一段路、怎么让它合规。读完那一节，你才知道什么数据能放进这个文件夹。
它每一步都会问你

当它要读文件、改文件、运行命令时，会先弹出来问你同不同意。这个确认机制非常重要，别嫌烦——它是你和一个能操作你电脑的 AI 之间唯一的安全带。

它要做什么你该怎么想
读文件基本都可以同意
改文件 / 新建文件看清楚是哪个文件。改的不该是你的原始数据
运行命令看一眼命令里有没有 rm、delete、drop 这类词——有就停下来问清楚
一个建议：别急着开"全部允许"它有个选项可以让你不用每次确认。前两周别开。这两周里你会通过一次次确认，逐渐建立起"它大概会做什么"的直觉——这个直觉比省下的那点点击值钱得多。
三个立刻能用的动作
让它读「读一下这个文件夹里的花名册，告诉我有哪些列、有没有明显的脏数据」
让它做「写一个脚本，把这三张表按工号合并，结果存成新文件」——第四篇章学的东西，现在它可以直接帮你跑
让它记「把我们刚才定的口径写进一个 CLAUDE.md 文件」——下一节的主题
今天就试建那个文件夹，扔几份假数据进去，让它读一遍。然后让它做一件你第四篇章里做过的活——你会立刻感觉到差别：不用贴数据、不用下载结果，它直接在你的文件夹里干完。

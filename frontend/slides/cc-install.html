这是这门课最高的一道坎，也是唯一一道。跨过去之后全是下坡。这一节写得比其他任何一节都啰嗦，因为卡在这里的人最多。

好消息：这一关比你想的容易
Claude Code 是工具，背后用哪个模型是可以换的。它可以接国产模型，全程不需要海外账号、不需要海外支付、API 流量也不出境。
这一节走的就是这条路——你只需要一个手机号能注册的国内账号，和人民币充值。

为什么可以这样：这正是第七篇章那句话提前兑现了——CC 是你的 harness，模型是租来的。换个模型，你的工作方式、你写的 CLAUDE.md、你造的那一整层东西，全都不变。

明确一下不需要什么不需要 Anthropic 账号 · 不需要海外信用卡 · 不需要科学上网。
如果你之前听说"用 Claude Code 得先解决网络"，那说的是接官方 API 的走法。接国产模型这条路没有这个问题。
四步，每步都能验证
1装 Node.js官网下安装包，一路下一步。装完敲 node -v，能打印版本号就成了
2换国内镜像不换会很慢甚至超时。这一步几乎决定成败，但只有一行
3装 Claude Code一行命令
4指向国产模型配两个环境变量，告诉它去哪儿找模型
# 2. 换国内镜像（不换会很慢） npm config set registry https://registry.npmmirror.com # 3. 装 Claude Code npm install -g @anthropic-ai/claude-code # 4. 告诉它用国产模型（把 你的KEY 换成你申请到的） export ANTHROPIC_BASE_URL=https://open.bigmodel.cn/api/anthropic export ANTHROPIC_AUTH_TOKEN=你的KEY # 启动 claude

第 4 步这两行是关键：它们让 CC 不再去找 Anthropic，而是去找国内的接口——所以既不用登录海外账号，流量也不出境。想让它永久生效（不用每次敲），让 AI 教你写进配置文件，一句话的事。

别自己查教程，让 AI 带你装

网上的教程会过时、会写给工程师看、会跳过它们觉得"显然"的步骤。最省事的做法是让 AI 一步步带你——下面这段发给任何一个国内 AI（豆包、DeepSeek、Kimi 都行），然后严格照做。

我要在我的电脑上安装 Claude Code，并接入国内的智谱 GLM 模型 （不使用 Anthropic 官方 API，我没有海外账号）。 我的情况： - 系统：Windows 11（或 macOS，按你的实际情况改） - 我完全没有编程经验，从来没用过终端/命令行 - 我不知道自己有没有装过 Node.js 请一步一步带我装，要求： 1. 每一步告诉我：在哪里操作、敲什么、按什么键 2. 每一步告诉我"看到什么就算成功了" 3. 一次只给我一步，我做完回复你"好了"，你再给下一步 4. 需要我做判断时，直接告诉我怎么判断，不要假设我知道 5. npm 请用国内镜像源 现在开始第一步。

第 3 条是关键：「一次只给我一步」。没有这句，它会一口气给你八步，你在第三步卡住之后就不知道自己在哪了。

卡住的时候
铁律：报错整段复制，贴回去问终端里的报错又长又难看，但你一个字都不需要看懂。全选、复制、贴给 AI，说「我按你说的做，报了这个错」。它解决这类问题的成功率极高。

两个高频坑先说在前面：①「命令找不到」——多半是 Node 没装好，或者要重开一次终端；② Windows 提示权限不足——用管理员身份重开终端再试。这两个直接告诉 AI，它知道怎么办。

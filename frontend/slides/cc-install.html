装上它：一步都不跳

这是这门课最高的一道坎，也是唯一一道。跨过去之后全是下坡。这一节写得比其他任何一节都啰嗦，因为卡在这里的人最多。

好消息：这一关比你想的容易
Claude Code 是工具，背后用哪个模型是可以换的。它可以接国产模型，全程不需要海外账号、不需要海外支付、API 流量也不出境。
这一节走的就是这条路——你只需要一个手机号能注册的国内账号，和人民币充值。

为什么可以这样：这正是第七篇章那句话提前兑现了——CC 是你的 harness，模型是租来的。换个模型，你的工作方式、你写的 CLAUDE.md、你造的那一整层东西，全都不变。

# 1. 装 Claude Code（Mac；Windows 见下一节） curl -fsSL https://claude.ai/install.sh | bash # 2. 告诉它用国产模型（把 你的KEY 换成你申请到的） export ANTHROPIC_BASE_URL=https://open.bigmodel.cn/api/anthropic export ANTHROPIC_AUTH_TOKEN=你的KEY # 启动 claude

别自己查教程，让 AI 带你装

网上的教程会过时、会写给工程师看、会跳过它们觉得"显然"的步骤。最省事的做法是让 AI 一步步带你——下面这段发给任何一个国内 AI（豆包、DeepSeek、Kimi 都行），然后严格照做。

我要在我的电脑上安装 Claude Code，并接入国内的智谱 GLM 模型 （不使用 Anthropic 官方 API，我没有海外账号）。 我的情况： - 系统：Windows 11（或 macOS，按你的实际情况改） - 我完全没有编程经验，从来没用过终端/命令行 - 我要用官方的一行命令安装器装，不要用 npm，也不要装 Node.js 请一步一步带我装，要求： 1. 每一步告诉我：在哪里操作、敲什么、按什么键 2. 每一步告诉我"看到什么就算成功了" 3. 一次只给我一步，我做完回复你"好了"，你再给下一步 4. 需要我做判断时，直接告诉我怎么判断，不要假设我知道 5. Windows 请先帮我确认我在 PowerShell 还是 CMD，两者命令不一样 现在开始第一步。

第 3 条是关键：「一次只给我一步」。没有这句，它会一口气给你八步，你在第三步卡住之后就不知道自己在哪了。

卡住的时候
铁律：报错整段复制，贴回去问终端里的报错又长又难看，但你一个字都不需要看懂。全选、复制、贴给 AI，说「我按你说的做，报了这个错」。它解决这类问题的成功率极高。

两个高频坑先说在前面：①「命令找不到」——九成是编辑器没彻底关掉重开；② Windows 上命令报语法错——多半是把 PowerShell 的命令敲进了 CMD（或反过来），下一节手册教你一眼认出自己在哪个窗口。这两个直接告诉 AI，它知道怎么办。

第六篇章 · 先把工具装上：终端与 Claude Code

装上它：一步都不跳

这是这门课最高的一道坎，也是唯一一道。跨过去之后全是下坡。这一节写得比其他任何一节都啰嗦，因为卡在这里的人最多。

你需要准备什么
一台你能装软件的电脑公司电脑装不了就用个人电脑。这一章不像第四篇章，没有"零安装"的变通路径
一个 Claude 账号需要付费订阅或 API 额度。这是真实成本，先知道再决定
三十分钟第一次装。以后再也不用装了
最重要的一句话：别自己查教程
网上的安装教程会过时、会写给工程师看、会跳过它们觉得"显然"的步骤。最好的做法是让 AI 带你装——打开任何一个 AI 对话工具，把下面这段发给它，然后严格按它说的一步步做。卡住就把报错原样贴回去。
我要在我的电脑上安装 Claude Code（终端版）。 我的情况： - 系统：macOS（或 Windows 11，按你的实际情况改） - 我完全没有编程经验，从来没用过终端 - 我不知道自己有没有装过 Node.js 或其他任何开发工具 请一步一步带我装，要求： 1. 每一步告诉我：在哪里操作、敲什么、按什么键 2. 每一步告诉我"看到什么就算成功了" 3. 一次只给我一步，我做完回复你"好了"，你再给下一步 4. 如果我需要判断什么，直接告诉我怎么判断，不要假设我知道 现在开始第一步。

第 3 条是关键：「一次只给我一步」。没有这句，它会一口气给你八个步骤，你在第三步卡住之后就不知道自己在哪了。

大致会经历什么（心里有个数）
1装 Node.js —— 一个运行环境，去官网下载安装包，一路下一步
2在终端里敲一行命令装 Claude Code
3第一次运行，它会让你登录 Claude 账号（会自动打开浏览器）
4看到它的欢迎界面，装完了
npm install -g @anthropic-ai/claude-code # 装完后，在任意文件夹里敲： claude
卡住的时候
铁律：报错整段复制，贴回去问终端里的报错又长又难看，但你一个字都不需要看懂。全选、复制、贴给 AI，说「我按你说的做，报了这个错」。它解决这类问题的成功率极高。

如果连着三轮还没解决，换个说法重新描述你的处境（系统版本、你已经做了哪几步、现在屏幕上显示什么），往往一下就通了。
今天就试就装这一件事。装完在终端里敲 claude，看到它跟你打招呼，这一节就过了。别急着让它干活——下一节才开始。

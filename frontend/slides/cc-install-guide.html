第六篇章 · 先把工具装上：终端与 Claude Code

安装完全手册：照着走，不用看视频

上一节是思路，这一节是手册。Windows 和 Mac 分开写，每一步都告诉你「看到什么算成功」，最后附一张报错对照表。卡住了先查这张表。

怎么用这一节：不用通读。跟着视频走的时候，卡在哪一步就翻到哪一步；视频看不了（在公司、没耳机、链接失效），就从头照着做。全程约 30 分钟，其中 20 分钟是等下载。
开始之前：确认三件事
①这台电脑你能装软件吗公司电脑装不了就换个人电脑。Windows / Mac 都行
②手机号能收验证码吗用来注册智谱账号
③能微信/支付宝付款吗订阅套餐用，人民币

不需要：Anthropic 账号、海外信用卡、科学上网。

第一步 · 开通智谱 GLM Coding（约 5 分钟）
做什么看到什么算成功
打开 bigmodel.cn/glm-coding，手机号注册登录进入控制台
完成实名认证状态显示已认证
订阅 GLM Coding Plan。先买最低档——够你学完这门课，不够再升套餐状态显示生效中
到「个人编程套餐 → 套餐概览」新建 API Key拿到一串以字母数字组成的 Key，复制存好
三个提醒① 价格和档位以官网为准，最低档在几十元/月的量级，比 Claude 官方订阅便宜一大截。
② API Key 只在创建时能完整看到一次，当场存进你的密码管理器，别截图丢群里。
③ 套餐是按周期限额的：用超了会等下个周期刷新，不会自动扣你账户余额——这点比按量付费安心，不会半夜跑出个账单。

Claude Code 是跑在 Node.js 上的，所以要先装它。去官网 nodejs.org 下 LTS 版本（写着 LTS 的那个，别下最新版）。

WindowsMac

安装双击，一路下一步，不用改任何选项双击，一路继续
装完关掉所有已打开的终端窗口（很重要）同左
打开终端开始菜单搜「终端」或「PowerShell」聚焦搜索「终端 / Terminal」
node -v npm -v

两条命令各自打印出一串版本号（像 v22.x.x），第二步就过了。报「不是内部或外部命令」/「command not found」→ 见文末报错表第 1 条。

第三步 · 换镜像 + 装 Claude Code（约 5 分钟）
# 换成国内镜像（不换会很慢甚至超时，这一步别跳） npm config set registry https://registry.npmmirror.com # 装 Claude Code npm install -g @anthropic-ai/claude-code # 验证 claude --version

最后一条打印出版本号就成了。Mac 上报权限错误（EACCES）→ 见报错表第 3 条，别急着用 sudo。

第四步 · 告诉它用国产模型（这一步最关键）

Claude Code 默认去找 Anthropic。配两个环境变量，把它指向国内接口。下面是永久生效的写法，配一次就不用管了。

Windows（在终端里敲，注意把 你的KEY 换成第一步拿到的）：

setx ANTHROPIC_BASE_URL "https://open.bigmodel.cn/api/anthropic" setx ANTHROPIC_AUTH_TOKEN "你的KEY"

敲完必须关掉终端重新打开，setx 对当前窗口不生效。也可以走图形界面：设置 → 系统 → 系统信息 → 高级系统设置 → 环境变量 → 用户变量新建两条。

Mac（macOS 默认用 zsh）：

echo 'export ANTHROPIC_BASE_URL=https://open.bigmodel.cn/api/anthropic' >> ~/.zshrc echo 'export ANTHROPIC_AUTH_TOKEN=你的KEY' >> ~/.zshrc source ~/.zshrc

验证有没有生效：

＃ Windows echo %ANTHROPIC_BASE_URL% ＃ Mac echo $ANTHROPIC_BASE_URL

打印出那个网址就对了。打印出空的或者原样输出变量名 → 没生效，重开终端再试一次。

第五步 · 成功长什么样
＃ 随便建一个文件夹，进去 claude

正常情况：它会显示欢迎信息，然后等你输入。如果它跳出来让你登录 Anthropic 账号或者打开浏览器，说明第四步没生效——回去检查环境变量，重开终端。

✓ 最后一个验证直接问它一句：「你现在用的是什么模型？」
它应该回答 GLM 系列而不是 Claude。答对了，整个安装就完成了。

1「不是内部或外部命令」
「command not found: node」		Node 没装好，或者终端没重开。先关掉所有终端窗口重新打开再试；还不行就重装 Node

想重来怎么办
＃ 卸载 Claude Code npm uninstall -g @anthropic-ai/claude-code ＃ 恢复默认 npm 源（一般不需要） npm config set registry https://registry.npmjs.org

Node.js 用系统的卸载程序删就行。装坏了不用怕，全都可以卸干净重来——这一步不会动你电脑上任何别的东西。

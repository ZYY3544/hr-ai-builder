第六篇章 · 先把工具装上：终端与 Claude Code

安装完全手册：15 步，从 Cursor 到 GLM

上一节是思路，这一节是手册。全程 15 步、5 个阶段，每步都标了「看到这个就算过了」——看不到就停下来查报错表，别硬往下做。

全程 15 步，分 5 个阶段，约 40 分钟（其中一半是等下载）。
每一步都有一行 ✓ 看到这个就算过了——看到了就往下走，没看到就停在原地查报错表，别硬着头皮往下做。
先看全景：你要走的 5 个阶段
阶段做什么步约需
一开通智谱账号，拿到 API Key1–45 分钟
二装 Cursor（一个带内置终端的编辑器）5–710 分钟
三装 Node.js 和 Claude Code8–1115 分钟
四把 Claude Code 接到 GLM 上12–145 分钟
五确认真的成功了151 分钟

为什么要装 Cursor？它本质是个带图形界面的编辑器，里面自带一个终端窗口。对没用过命令行的人来说，在一个正常的软件窗口里操作，比对着一个漆黑的终端心理压力小得多。而且后面写 CLAUDE.md、看它改了什么文件，都在同一个窗口里完成。
（如果你已经装过 VS Code，可以直接用 VS Code，它的内置终端是一样的，跳过阶段二。）

阶段一 · 开通智谱，拿到 Key（第 1–4 步）

第 1 步 · 注册账号
打开 bigmodel.cn/glm-coding，用手机号注册并登录。

✓ 看到这个就算过了能进到控制台页面，右上角显示你的账号。

第 2 步 · 实名认证
按页面提示完成实名。不做这一步后面买不了套餐。

✓ 看到这个就算过了账号状态显示「已实名」。

第 3 步 · 订阅 GLM Coding Plan
在 GLM Coding 页面选套餐，微信或支付宝付款。先买最低档就够学完这门课，不够以后随时升。

先回答你现在最想问的那个问题：多少钱最低档在每月几十元的量级，比 Claude 官方订阅便宜一个数量级。
准确价格以官网当时显示为准（会调整，也常有新用户优惠）——但有一点可以放心：价目表在你实名认证之前就能在页面上看到，不需要"先跳下去才知道水多深"。觉得不合适，那一步退出来就行。
✓ 看到这个就算过了套餐状态显示「生效中」，能看到本周期的额度。
这里有个让人安心的机制这个套餐是按周期限额的：用超了会等下个周期刷新，不会自动扣你账户余额。所以不存在"半夜跑出一个大额账单"这种事。

第 4 步 · 新建 API Key
进「个人编程套餐 → 套餐概览」，点新建 API Key，立刻复制存好。

✓ 看到这个就算过了拿到一串字母数字组成的 Key，已经存进你的密码管理器或备忘录。
✕ 这一步最容易吃亏Key 只在创建时完整显示一次，关掉页面就再也看不到全文了（只能重新建一个）。当场就存，别想着"等会儿再说"。也别截图丢在群里——那等于把你的付费额度公开。
阶段二 · 装 Cursor（第 5–7 步）

第 5 步 · 下载 Cursor
打开 cursor.com，点 Download。它会自动识别你的系统给对应的版本。

✓ 看到这个就算过了下载目录里出现安装包（Windows 是 .exe，Mac 是 .dmg）。

第 6 步 · 安装并打开
Windows 双击 .exe 一路下一步；Mac 打开 .dmg 把图标拖进「应用程序」。第一次打开可能问你要不要导入设置、要不要登录——都可以跳过，我们只用它的终端。

✓ 看到这个就算过了Cursor 窗口打开了，能看到左侧文件栏和中间的编辑区。

第 7 步 · 打开内置终端
在 Cursor 里按 Ctrl + `（Mac 是 Control + `，那个键在数字 1 左边、Esc 下面）。也可以走菜单：Terminal → New Terminal。

✓ 看到这个就算过了窗口下方弹出一个区域，最后一行有个可以打字的光标。接下来所有命令都敲在这里。
先适应两秒这个区域就是"终端"。它看起来吓人，但你要做的只有一件事：把命令复制进去，按回车，看结果。敲错了不会弄坏电脑，最多是报个错。
阶段三 · 装 Node.js 和 Claude Code（第 8–11 步）

第 8 步 · 先看看有没有装过 Node
在终端里粘贴这一行，回车：

node -v
✓ 两种结果都正常打印出 v20.x.x 之类的版本号 → 已经有了，直接跳到第 10 步。
报「不是内部或外部命令」或「command not found」 → 没装，继续第 9 步。

第 9 步 · 装 Node.js
打开 nodejs.org，下载标着 LTS 的那个版本（不要下最新版）。Windows 选 .msi，Mac 选 .pkg，双击一路下一步，不用改任何选项。

✕ 装完必须做这件事完全关掉 Cursor 再重新打开，然后重新按 Ctrl + ` 开终端。
不重开的话，终端还认不出新装的 Node——这是第 8 步之后最高频的卡点。
✓ 看到这个就算过了重开终端后再敲一次 node -v，这次打印出版本号了。

第 10 步 · 换成国内镜像
这一步别跳。不换的话下一步会非常慢，甚至直接超时失败。

npm config set registry https://registry.npmmirror.com
✓ 看到这个就算过了命令跑完没有任何输出就是成功了（这类命令成功时是静默的）。想确认可以敲 npm config get registry，应该打印出那个 npmmirror 地址。

第 11 步 · 装 Claude Code

npm install -g @anthropic-ai/claude-code

会滚动一堆日志，等它停下来。然后验证：

claude --version
✓ 看到这个就算过了打印出一个版本号。
这一步最常见的两个错Mac 报 EACCES 权限错误 → 见报错表第 3 条，先别用 sudo。
Windows 报权限不足 → 关掉 Cursor，右键「以管理员身份运行」重开，再来一次。
阶段四 · 接到 GLM 上（第 12–14 步）

Claude Code 默认会去找 Anthropic。这三步是把它指向国内接口——做完就不需要海外账号、不需要科学上网了。

第 12 步 · 设置两个环境变量
把下面的 你的KEY 换成第 4 步存下来的那串，然后整段粘进终端。Windows 和 Mac 写法不同，认准你的系统。

Windows：

setx ANTHROPIC_BASE_URL "https://open.bigmodel.cn/api/anthropic" setx ANTHROPIC_AUTH_TOKEN "你的KEY"

Mac：

echo 'export ANTHROPIC_BASE_URL=https://open.bigmodel.cn/api/anthropic' >> ~/.zshrc echo 'export ANTHROPIC_AUTH_TOKEN=你的KEY' >> ~/.zshrc source ~/.zshrc
✓ 看到这个就算过了Windows 会打印「成功: 指定的值已得到保存」；Mac 没有输出就是成功。

第 13 步 · 重开终端，确认变量真的生效了
Windows 必须关掉 Cursor 重新打开（setx 对已经开着的窗口不生效，这是最高频的"我明明配了却不管用"）。Mac 上如果跑过 source 就不用重开。
然后敲：

＃ Windows echo %ANTHROPIC_BASE_URL% ＃ Mac echo $ANTHROPIC_BASE_URL
✓ 看到这个就算过了打印出 https://open.bigmodel.cn/api/anthropic。
如果打印出的是空行、或者原样吐回变量名 → 没生效，回第 12 步重来，Windows 记得一定要重开。

第 14 步 · 启动
随便找个空文件夹（比如桌面新建一个叫 hr-agent 的），在 Cursor 里打开它（File → Open Folder），然后在终端敲：

claude
✓ 看到这个就算过了它显示欢迎信息，然后停在那里等你输入。
✕ 如果它让你登录 Anthropic 账号或自动打开了浏览器说明第 12 步没生效。不要去注册 Anthropic 账号——退出来（按 Ctrl+C 两次），回第 13 步检查变量。
阶段五 · 确认真的成功（第 15 步）

第 15 步 · 问它一句话
在 claude 的输入框里直接打字：

你现在用的是什么模型？请直接回答模型名称。
✓ 全部完成它回答的是 GLM 系列（而不是 Claude）——说明整条链路通了：Claude Code 这个工具在你电脑上跑着，背后接的是国内的模型。

你已经跨过这门课最高的那道坎了。
如果它说自己是 Claude那说明它还在连官方接口，环境变量没接上。回第 13 步。
（注意：模型有时会答不准自己的身份，如果你不确定，可以到智谱控制台看一眼这次调用有没有消耗额度——有消耗就说明确实走的是 GLM。）

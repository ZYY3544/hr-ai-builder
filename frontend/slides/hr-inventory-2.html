第六篇章 · 选对活：先把部门的活盘一遍

每条标：它能干 / 干不了 / 干了得有人兜

清单有了，现在给每一条打标。只分三类，不要分五类——分得越细，越容易把「不确定」伪装成「中等」。

三类，不是五类
标什么样的活属于这一类判据
🟢 它能干 输出可以被机械验证，错了立刻看得见，而且错的代价可承受 格式转换、信息提取、初稿生成、按明确规则归类
🔴 它干不了 需要它拿不到的上下文，或者错误不可逆 解雇决定、薪酬定档、员工冲突判断、涉及个人前途的最终结论
🟡 干了得有人兜 它能大幅提效，但错误不会自己暴露 简历初筛、绩效摘要、调研归纳、政策问答
🟡 这一类是全表最重要的，而且最容易被误标成 🟢。 因为它跑起来「看着挺对」——问题恰恰在这：看着挺对但你没验过，而它的错误是沉默的。 上一章那句「AI 只做召回、判定必须回原文」，管的就是这一类。
三个判断问题，按顺序问
问题答案指向
1它做错了，你多久会发现？ 立刻 → 🟢 ｜ 几天后 → 🟡 ｜ 永远不会 → 🟡，而且必须设闸
2做这件事需要的信息，全在文字里吗？ 全在 → 可考虑 ｜ 有一部分在你脑子里 / 在会议室里 / 在人际关系里 → 🔴
3错了以后能撤回吗？ 能撤 → 🟢/🟡 ｜ 撤不回（人已经走了、话已经说了）→ 🔴

顺序不能换。第 1 题先问，是因为「错误可见性」比「准确率」重要得多—— 一个 80% 准确但错了你马上知道的东西，比一个 95% 准确但错了没人发现的东西安全。

给简历初筛打个标
简历初筛 → 🟡 干了得有人兜 Q1 多久发现？漏掉一个好候选人——永远不会发现，对方不会来问，你也不会知道 → 指向 🟡
Q2 信息全在文字里吗？硬性条件在，但「这个人适不适合我们团队」不在 → 部分在
Q3 能撤回吗？候选人被刷掉后基本不会回来了 → 偏 🔴

结论：🟡，而且是 🟡 里最危险的那种——所以必须设闸（只召回不判定 + 人看原文复核）。
一个常见的误标
✕ 把「员工政策问答」标成 🟢 理由通常是「它答错了员工会来问啊，所以错误可见」。
但不会。员工得到一个听起来很确定的错误答案，多半就照着做了——比如把年假规则理解错， 到年底才发现。那时候责任在谁？
→ 正确标法是 🟡，而且要加一条硬约束：不确定时必须说「我不知道，请咨询 HRBP」。
第二步

先问「错了多久能发现」，再问「准不准」

  1. 只分三类。分五类会让你把「不确定」藏进「中等」里，那等于没判断。
  2. 错误可见性优先于准确率。沉默的错误比明显的错误危险得多。
  3. 🟡 是最大的一类，也是这个岗位的主战场。🟢 不用你、🔴 不该碰，你的价值全在怎么给 🟡 设闸上。
  4. 标完让业务方过一遍。你判断「错了会怎样」的依据是经验，业务方的经验和你不一样——他们会推翻你几条，那几条通常最值钱。
